                Troubleshooting: Application Fails to Start (Port 5051 in Use)
                 
                If the application fails to start because port 5051 is already in use, you can find and kill the conflicting process using the Command Prompt (Run as Administrator):
                 
                  REM 1. Find the Process ID (PID) using port 5051
                 netstat -ano | findstr :5051
                                                      REM 2. Kill the process forcefully (Replace <PID> with the number from step 1)
                 taskkill /PID <PID> /F
