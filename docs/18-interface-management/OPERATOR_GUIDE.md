# Operator Guide: Visual Interface Management System

## Step-by-Step Operator Steps
1. Navigate to the **🔧 Interface Manager** tab in the top navigation panel.
2. Select your single target switch IP and vendor type in the sidebar.
3. Click **Discover Interfaces**. This will load all port configurations and display them on the visual grid map.
4. Click on the target interface port card. The configuration drawer opens below.
5. Inspect the current config and make modifications inside the editable Proposed Configuration field.
6. Click **Validate Config** to trace errors and display validation checks status.
7. Click **Deploy Config** to prompt the safety verification modal. Confirm the diff, check consent boxes, and click **Confirm and Deploy**.
