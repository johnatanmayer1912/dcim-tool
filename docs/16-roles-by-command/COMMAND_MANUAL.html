Introduction

This manual lists every AI IDE command for Network Swiss Tool Pro. Commands activate multiple team roles (R-ENG, R-QA, R-LIB, …) automatically for a holistic result.

Designed for offline Windows PC use by network engineers. Open this file in a browser from the repo — no internet required.

Markdown source: docs/17-roles-by-command/ROLES_BY_COMMAND_REFERENCE.md
Workflow hub: docs/13-master-prompts/PROMPT_COMMAND_CENTER.md

How to use

  1. Click Copy on any command block below.
  2. Paste into Cursor chat and send.
  3. AI loads the workflow file and all listed roles.
  4. Review deliverables (reports under docs/14-bug-reports/, action logs).

Docs Full docs sync

Aliases: /full-docs-sync · full docs sync · sync all documentation

Roles: R-GOV-LIB, R-LIB, R-RECON, R-ARCH, R-QA, R-REL

Workflow: docs/13-master-prompts/roles/FULL_DOCS_SYNC.md

Complete parity: CODE_INVENTORY, API docs, plugin READMEs, 15-rebuild-roadmap, PROMPT_REGISTRY, link validation.

/full-docs-sync Execute docs/13-master-prompts/roles/FULL_DOCS_SYNC.md — all phases. Run python scripts/validate_docs_links.py before and after. Log: docs/13-master-prompts/action-logs/YYYY-MM-DD_full-docs-sync.md

Council Find all bugs and fix

Aliases: /find-all-bugs-and-fix · find all bugs and fix

Roles: ALL council (R-GOV-LIB, R-ARCH, R-ENG, R-QA, R-SEC, R-OBS, R-LIB, R-REL, R-PROD, R-COUNCIL)

Workflow: docs/13-master-prompts/roles/FIND_ALL_BUGS_AND_FIX.md

Output: Bug list with severity · root cause · fix prompts per bug · FIX-ALL-CONSOLIDATED-PROMPT.md for one-shot fix run.

/find-all-bugs-and-fix Execute docs/13-master-prompts/roles/FIND_ALL_BUGS_AND_FIX.md Phase A: Full bug sweep (all roles) → docs/14-bug-reports/W-BUG-SWEEP-*.md Phase B: Council synthesis → 01-prioritized-bug-list.md with Critical/High/Medium/Low Phase C: Generate 04-fix-workflow/FIX-ALL-CONSOLIDATED-PROMPT.md Each bug folder must include: bug-report.md, fix-prompt.md, validation-prompt.md

After sweep — fix everything

execute fix all from latest bug sweep Run docs/14-bug-reports/04-fix-workflow/FIX-ALL-CONSOLIDATED-PROMPT.md in priority order. After each bug: pytest + _prebuild.py. Then /full-docs-sync.

Auto-fix (find + fix in one session)

/find-all-bugs-and-fix auto proceed Same as find-all-bugs-and-fix but continue into fixes without waiting. Stop only on test regression or council escalation.

Aliases: /next-steps · what are the next steps to improve the program

Roles: ALL council — R-COUNCIL synthesizes

360° recommendations for network engineers: time saved, simplicity, professionalism. Each item includes decision, why, complexity (S/M/L/XL), and implementation prompt.

/next-steps Execute docs/13-master-prompts/roles/NEXT_STEPS_COUNCIL.md Output: docs/14-bug-reports/03-team-contributions/NEXT-STEPS-COUNCIL-YYYY-MM-DD.md Each NEXT-* row: Decision, Why, What it adds, Complexity, Roles, Implementation prompt (copy-paste) Focus: engineer effectiveness, offline PC, time-saving workflows
