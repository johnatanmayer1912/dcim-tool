# Plugin Prompt: serial_number

## Purpose

Retrieve chassis and module serial numbers for asset inventory.

## Requirements

- Support IOS, NXOS, JunOS
- Module serials optional
- Multiple serial patterns

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| include_modules | checkbox | Include line card serials |
