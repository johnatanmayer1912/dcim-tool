# Plugin Prompt: critical_logs

## Purpose

Retrieve and filter syslog entries by severity level.

## Requirements

- Support IOS, NXOS, JunOS
- Severity filtering
- Configurable count

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| log_count | integer | Number of entries (5-100) |
| severity_filter | dropdown | Minimum severity |
