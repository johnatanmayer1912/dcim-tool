# Plugin Prompt: interface_errors

## Purpose

Retrieve interface error counters for troubleshooting.

## Requirements

- Support IOS, NXOS, JunOS
- CRC, giant, runt detection
- Threshold filtering

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| min_errors | integer | Minimum error threshold |
| interface_filter | string | Regex filter |
