# Platform Compatibility — Network Discovery & Crawl Plugin

# Purpose
Maintains the verified OS and software version compatibility matrix for the Network Discovery & Crawl plugin.

# Scope
Cisco IOS, IOS-XE, NX-OS, Juniper Junos.

---

## Compatibility Matrix

| Platform | Verified OS Version | Protocol | Status |
| :--- | :--- | :--- | :--- |
| **Cisco IOS** | 12.x, 15.x | CDP, LLDP | **Fully Supported** |
| **Cisco IOS-XE** | 3.x, 16.x, 17.x | CDP, LLDP | **Fully Supported** |
| **Cisco NX-OS** | 7.x, 9.x, 10.x | CDP, LLDP | **Fully Supported** |
| **Juniper Junos** | 12.x, 15.x, 21.x | LLDP | **Fully Supported** (Junos does not run CDP) |
