# Changelog: unused_trunk_pruner

All notable changes to this plugin will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.1] - 2026-04-23

### Changed
- Improved cross-platform support (IOS/NXOS/JUNOS)
- Robust hostname detection using connection prompt
- Improved regex for trunk parsing

## [1.0.0] - 2026-04-23

### Added
- Initial release of unused_trunk_pruner plugin
- Ghost VLAN detection and analysis
- Multi-platform support (Cisco IOS, Cisco NX-OS, Juniper JunOS)
- VLAN range parsing for complex formats
- Human-readable report generation with pruning recommendations
- Platform-specific command selection
