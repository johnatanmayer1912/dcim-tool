# Platform Compatibility — Template-Based Configuration Generator Plugin

# Purpose
Maintains the verified OS and software version compatibility matrix for the Template-Based Configuration Generator plugin.

# Scope
Cisco IOS, IOS-XE, NX-OS, Juniper Junos.

---

## Compatibility Matrix

| Platform | Verified OS Version | Render Capability | Status |
| :--- | :--- | :--- | :--- |
| **Cisco IOS** | 12.x, 15.x | NTP, Syslog, Banners, ACLs | **Fully Supported** |
| **Cisco IOS-XE** | 3.x, 16.x, 17.x | Interface, Routing, NTP | **Fully Supported** |
| **Cisco NX-OS** | 7.x, 9.x, 10.x | vPC, VLANs, Syslog | **Fully Supported** |
| **Juniper Junos** | 12.x, 15.x, 21.x | System Services, NTP | **Fully Supported** |
