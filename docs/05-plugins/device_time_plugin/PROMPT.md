# Plugin Prompt: device_time

## Purpose

Retrieve device system time and NTP status from network devices.

## Requirements

- Support IOS, NXOS, JunOS
- NTP status optional
- Multi-command fallbacks

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| show_ntp | checkbox | Include NTP sync status |
