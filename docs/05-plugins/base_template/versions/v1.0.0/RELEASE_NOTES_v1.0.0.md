# Release Notes: base_template v1.0.0

Initial release of the Base Plugin Template for Network Swiss Tool Pro v6.0.

- Complete plugin contract implementation
- 4 parameter types (integer, string, checkbox, dropdown)
- Multi-platform command fallbacks
- Safe connection handling
- Standardized JSON return format

### Documentation
- Full docstring with version history
- 6 required documentation files
- Version archive structure
- manifest.json metadata
