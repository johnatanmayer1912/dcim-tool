# Plugin Prompt: environment_status

## Purpose

Retrieve environment health status (temperature, fans, power).

## Requirements

- Support IOS, NXOS, JunOS
- Temperature, fan, power monitoring
- Alert filtering

## Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| alert_only | checkbox | Show only warnings/failures |
| include_temp | checkbox | Include temperature |
