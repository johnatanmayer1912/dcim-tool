# Changelog: stp_topology_visualizer

All notable changes to this plugin will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.1] - 2026-04-23

### Changed
- Improved cross-platform support (IOS/NXOS/JUNOS)
- Robust hostname detection using connection prompt
- Platform-specific command mapping for better accuracy

## [1.0.0] - 2026-04-23

### Added
- Initial release of stp_topology_visualizer plugin
- Root Bridge detection and VLAN mapping
- Blocked port analysis
- Multi-platform support (Cisco IOS, Cisco NX-OS, Juniper JunOS)
- Human-readable report generation
- Platform-specific command selection
