## High-severity repro steps (NEW-H1 … NEW-H6)

### NEW-H1 — Visited before SSH (no retry)

**Repro:** Start a live Discovery crawl with a seed IP that fails SSH on first attempt (wrong password, ACL drop, or timeout). Fix credentials or network, then re-run crawl **without** changing seeds. **Expected (bug):** Device is skipped for the entire run because `visited.add(visited_key)` runs at lines 293–296 in `network_discovery.py` **before** `safe_connection()`. **Expected (fixed):** Failed hop is not marked visited (or visited removed on failure) so a later queue pass or re-run can connect.

### NEW-H2 — dry_run ignored

**Repro:** Enable Discovery **Demo mode** or any UI/API path that sets `dry_run: true` in plugin params. Set breakpoint or log at `crawl_network_multi_seed` line 258. **Expected (bug):** `dry_run = False` is hardcoded; BFS still attempts `safe_connection` for queued IPs when not in plugin-level demo path. **Expected (fixed):** `dry_run = bool(params.get('dry_run'))` skips SSH and only uses parser/demo data.

### NEW-H3 — CLI duplicate connect (TOCTOU)

**Repro:** Open CLI terminal tab, select a device, trigger **Connect** twice in quick succession (double-click or two browser tabs same session). **Expected (bug):** `create_cli_session` in `cli_manager.py` releases `_session_lock` before `cli.connect()` completes; two Paramiko sessions may open; second registration overwrites `_cli_sessions[session_id]`, leaking the first. **Expected (fixed):** Lock held until connect finishes or a `connecting` placeholder blocks duplicate connects.

### NEW-H4 — Unlocked job dicts + unbounded STP jobs

**Repro:** Start multiple STP Swiss Tools scans without restarting the app (10+ jobs). Poll `/api/stp/status` for old job IDs — they remain in `_stp_jobs`. Optionally run Discovery + STP concurrently and poll status rapidly. **Expected (bug):** `_stp_jobs` grows without prune (unlike `_discovery_jobs` max 50); no `threading.Lock` on shared job dicts despite comment at `vlan_checker_web.py` ~1396. **Expected (fixed):** STP job cap/TTL and lock around job read/write.

### NEW-H5 — Junos LLDP local port parses as colon

**Repro:** Run Discovery against a Junos device with LLDP neighbors, or unit-test `_parse_juniper_lldp_detail` with `tests/fixtures/discovery/junos_lldp_detail.txt`. Inspect edge `f_port` for LLDP links. **Expected (bug):** After `split("Local Interface")`, block begins with `    : ge-0/0/0`; regex `^\s*(\S+)` at line 744 captures **`:`** instead of `ge-0/0/0`. **Expected (fixed):** Explicit pattern `Local Interface\s*:\s*(\S+)`.

### NEW-H6 — Junos MAC trace Cisco column layout

**Repro:** Diagnostics → MAC trace on inventory with a Juniper EX/QFX where MAC exists in `show ethernet-switching table`. Compare CLI output columns to UI path summary VLAN/port. **Expected (bug):** `mac_trace.py` lines 65–72 use `parts[0]` as VLAN and `parts[-1]` as port (Cisco MAC table shape); Junos row layout differs → wrong or empty VLAN/port while `found=True`. **Expected (fixed):** Platform-specific parsers for Junos (and SRX ARP).
