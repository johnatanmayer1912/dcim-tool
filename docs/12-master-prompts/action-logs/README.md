# Action Logs

Per `PROMPT_GOVERNANCE_POLICY.md`, log meaningful role invocations here.

**Filename:** `YYYY-MM-DD_<short-slug>.md`

**Minimum fields:** per `ROLE_USAGE_STANDARD.md` (G-14) — findings, recommendations, decisions, risks, files reviewed/changed, versions, verified, open items.

Copy template: `roles/_ACTION_LOG_SNIPPET.md`

See `PROMPT_USAGE_MANUAL.md` and `PROMPT_ACTIVATION_POLICY.md` for workflow.
