External GUI audit — thesis

Design for night-shift operators: status first, zero hunt for Cancel, dense but legible tables, icon rail for muscle memory. Teal = healthy signal; amber/rose reserved for risk.
  • Icon rail + context drawer separates “where am I” from “what’s my scope”.
  • Persistent job strip + progress bar always on-screen (never buried in a console).
  • Metrics row answers “is the fleet OK?” before reading logs.
  • Split pane: evidence table + live timeline — both first-class.
