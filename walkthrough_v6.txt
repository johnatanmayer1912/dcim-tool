 PLUGIN CONTRACT
===============================================================================

Every plugin must implement:

1. METADATA DICTIONARY:
   
   METADATA = {
       "plugin_id": "my_plugin",
       "display_name": "My Plugin",
       "version": "1.0.0",
       "category": "Audit",
       "description": "What this plugin does",
       "required_params": {
           "param_name": {
               "type": "integer|string|checkbox|dropdown",
               "label": "Display Label",
               "required": True,
               "default": "optional"
           }
       }
   }

2. RUN FUNCTION SIGNATURE:

   def run(device, credentials, params, config, log_func):
       """
       device: {'host': '...', 'device_type': '...', 'group': '...'}
       credentials: {'username': '...', 'password': '...', 'secret': '...'}
       params: Dict of user inputs validated against METADATA
       config: Global application settings
       log_func: Callable for real-time UI logging
       
       Returns: {'status': 'success|fail', 'data': {...}, 'error': '...'}
       """

===============================================================================
 USAGE EXAMPLES
===============================================================================

CREATE A NEW PLUGIN:
1. Copy modules/plugins/base_template.py
2. Rename to your_plugin.py
3. Update METADATA dictionary
4. Implement run() function
5. Save to modules/plugins/
6. Click "Reload Registry" in Web UI

UPLOAD A PLUGIN:
1. Click "Upload Plugin" button
2. Select .py file
3. System validates and promotes if valid
4. Plugin appears in list

EXECUTE A PLUGIN:
1. Click plugin name in sidebar
2. Fill required parameters
3. Click "Execute Plugin"
4. View logs in console

ROLLBACK A PLUGIN:
1. Use API: POST /api/plugins/rollback
2. Body: {"plugin_id": "...", "backup_filename": "..."}
3. Or manually restore from backups/plugins/
