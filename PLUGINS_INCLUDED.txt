================================================================================
PLUGIN USAGE
================================================================================

1. All plugin files are in the /plugins folder
2. To activate a plugin:
   a. Open the web interface at http://127.0.0.1:5000
   b. Click the "Plugin Tools" tab
   c. Click "Reload Registry" to see available plugins
   d. Select a plugin from the list
   e. Fill in required parameters
   f. Click "Execute Plugin"

3. Plugins are validated by the Gatekeeper system before execution
4. Previous versions can be restored via the Rollback Manager

HARDCODED BUILD POLICY
================================================================================

The following are MANDATORY for all offline builds:

✅ ALL plugins from modules/plugins/ are included
✅ NO plugin exclusions are permitted
✅ Plugins are copied to dist_package/plugins/
✅ Plugin documentation is included in dist_package/docs/plugins/
✅ Users receive complete set - they decide what to use
✅ Build script validates all plugins are present
✅ Spec file includes entire plugins directory

This policy ensures:
- Complete offline functionality (no internet required)
- Full documentation availability
- Consistent version tracking across the platform
- Complete rollback capability for all versions
- Audit compliance

See: docs/00_MASTER/PLUGIN_BUNDLING_POLICY.md

================================================================================
ADDING NEW PLUGINS TO FUTURE BUILDS
================================================================================

When new plugins are created:

1. Create plugin file in modules/plugins/{plugin_id}.py
2. Create documentation in docs/plugins/{plugin_id}/ (6 files)
3. Add plugin to build_scripts/NetworkSwissToolPro_v6.9.22_OFFLINE.spec hiddenimports
4. Update this manifest (PLUGINS_INCLUDED.txt)
5. Rebuild distribution package

The new plugin will automatically be included in the next build.
