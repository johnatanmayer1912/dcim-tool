## Prompt Standards

All prompts in this directory follow the standardized structure:

1. **Role Definition** - Who the AI is acting as
2. **Context** - Background and current state
3. **Task Description** - What needs to be done
4. **Constraints** - Limitations and rules
5. **Step-by-Step Instructions** - Detailed execution steps
6. **Expected Output Format** - How to format responses
7. **Failure Handling Rules** - What to do when things go wrong
8. **Style/Tone Rules** - Communication style guidelines
