## 3. CORE ARCHITECTURAL CAPABILITIES

### 3.1 Interactive End-to-End L3 Path Tracer (Hop-by-Hop Flow Simulation)
- Algorithm: Pure deterministic Longest Prefix Match (LPM) on multi-vendor routing tables (`modules/routing_analyzer/path_tracer.py`).
- Resolution Sequence:
  1. Ingress Resolution: Match Source IP against connected/local subnets across all topology devices.
  2. Hop Progression: Iterate up to 30 hops by querying the routing table for the most specific prefix matching the Destination IP.
  3. Gateway Forwarding: If no next-hop IP is explicitly present, fall back to gateway analysis (`l3_gateways.json`).
  4. Cycle & Loop Detection: Detect revisiting devices and tag status as `loop_detected` with detailed diagnosis.
- Web API: `POST /api/l3/trace-path` returning `{complete, status, ingress_device, egress_device, hops, path_nodes, path_edges}`.
- Visualization: Interactive Path Tracer toolbar (`#trace-src-ip`, `#trace-dst-ip`, `#btn-trace-flow`, `#btn-clear-trace`) with Vis.js animated flow lines and sidebar `#trace-hops` cards.

### 3.2 Unified Multi-Layer Canvas with Dedicated STP Layer Toggle
- Single unified canvas (`utils/topo_map_shell.py`) with layer buttons:
  - `Physical`: Bidirectional CDP/LLDP cables only.
  - `L2`: All Layer-2 adjacencies including one-sided links.
  - `L3`: Layer-3 routing adjacencies (OSPF, BGP, EIGRP, Static).
  - `Overlay`: EVPN/VXLAN NVE peers from CLI telemetry.
  - `STP`: Dedicated Spanning-Tree Protocol view.
- STP Layer Visual Contract:
  - Root Bridges: Highlighted in solid Gold (`#f59e0b`).
  - Forwarding Links: Bright green (`#10b981` / `#22c55e`).
  - Blocking / Alternate / Discarding Ports: High-visibility Red with dashed styling (`#ef4444`, dashes `[4, 4]`).
  - URL Hash Navigation: Deep-linking via `#layer=stp`, `#layer=l3`, `#layer=l2`.

### 3.3 Consolidated Inventory Quad-Format Export with Hardware UUID Deduplication & Audit
- Consolidated engine (`utils/asset_warranty_consolidator.py`):
  - Ingest multiple reports simultaneously from `reports/` and `reports/asset_warranty_input/` (CSV, HTML, JSON, TXT).
  - **Hardware UUID Validation**: Normalizes physical Serial Number as the device's authoritative UUID (`SN:<SERIAL>`).
  - **Duplicate Device Removal & Attribute Merging**: Detects when 2 or more identical devices exist across ingested files. Rather than discarding metadata, non-destructively merges attributes (combining hostnames, IPs, models, and EOL dates) and logs conflicts.
  - **Statistical Integrity**: Re-computes summary metrics (`model_counts`, `warranty_status_counts`) strictly on unique deduplicated devices, eliminating count inflation.
  - **Dedicated Duplicates Audit Across Quad Exports**:
    1. Master HTML: Amber summary cards and dedicated "⚠️ Duplicate Hardware Audit" table detailing each duplicate UUID, occurrence counts, sources, and conflict warnings.
    2. Master CSV: Clean RFC-4180 comma-delimited export of unique master devices.
    3. Master JSON: Structured JSON with `duplicates_summary` and `duplicates_audit` array.
    4. Master XLSX: Beautifully styled Excel spreadsheet via `openpyxl` with two distinct tabs: `"Master Inventory"` and `"Duplicates Audit"`.
- Web UI & Serving: Endpoints `POST /api/reports/asset-warranty/consolidate`, `GET /reports/asset-warranty/<filename>`. In-browser status card displays unique device count and yellow duplicates merged badge.

## 4. SECURITY, ZERO-TRUST & CREDENTIAL FALLBACK
- 3-Tier Fallback Enforcement:
  All device connections and discovery crawls must accept Primary, Secondary, and Third credentials.
  Always attempt in order: Primary -> Secondary -> Third. Never fail early if secondary or tertiary credentials remain untried.
- Zero-Trust Invariant:
  - Passwords and enable secrets must NEVER be logged to console, session files, job outputs, or DOM attributes.
  - Credential IDs only over the wire. Passwords stay locked in `CredentialManager` vault memory until Netmiko dispatch.
- Extensive Logging:
  - Mirror every connection attempt, retry, and tier fallback to console and session file (`logs/sessions/`).
